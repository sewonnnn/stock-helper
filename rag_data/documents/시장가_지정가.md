# 시장가 주문과 지정가 주문 (Market Order vs Limit Order)

## 시장가 주문 (Market Order)
현재 시장에서 즉시 매수/매도하는 주문입니다.
- 장점: 즉시 체결됨
- 단점: 원하는 가격과 다를 수 있음 (슬리피지 발생 가능)
- 용도: 빠르게 매매하고 싶을 때

## 지정가 주문 (Limit Order)
특정 가격을 지정하여 그 가격 이하(매수) 또는 이상(매도)일 때만 체결되는 주문입니다.
- 장점: 원하는 가격에 매매 가능
- 단점: 체결되지 않을 수 있음
- 용도: 특정 가격에서 사거나 팔고 싶을 때

## 기타 주문 유형
- 스톱 주문 (Stop Order): 특정 가격에 도달하면 시장가 주문으로 전환
- 스톱 리밋 주문 (Stop Limit Order): 특정 가격에 도달하면 지정가 주문으로 전환
- GTC (Good Till Cancelled): 취소할 때까지 유효한 주문

## 초보자 팁
- 거래량이 많은 대형주는 시장가 주문도 괜찮습니다.
- 거래량이 적은 소형주는 지정가 주문을 추천합니다.
- 장 시작 직후(9:30 AM ET)에는 변동성이 크므로 지정가 주문이 안전합니다.
